# Orlumi Website Roadmap

## Roadmap Principle

Build the smallest complete brand website first. Do not publish empty features merely to make the site appear larger.

## Phase 0 — Brand Foundation

Status: substantially complete

- [x] Define Orlumi as the parent brand
- [x] Establish `Our Worlds`
- [x] Establish the unnamed ancient tree motif
- [x] Create brand and specialist documentation
- [ ] Confirm final public contact email
- [ ] Confirm whether the primary brand line remains `Small worlds. Gentle discoveries.`

## Phase 1 — Brand Homepage v1

Goal: a polished, responsive official brand homepage.

Required:

- [ ] complete `styles.css`
- [ ] complete progressive-enhancement `script.js`
- [ ] design brand hero with partial tree/branch motif
- [ ] create distinct cards for Little Explorer and Petal Nook
- [ ] add About Orlumi section
- [ ] add functional contact and legal footer
- [ ] create privacy policy page
- [ ] add favicon and social preview image
- [ ] verify metadata and canonical URL
- [ ] test mobile, tablet and desktop
- [ ] test keyboard and reduced-motion behaviour

Launch criterion: the site must look intentional even before official game screenshots exist.

## Phase 5 — Press and Growth

Add only when there is a real communications need.

- [ ] press kit
- [ ] downloadable logos and approved screenshots

- [ ] social links
- [ ] newsletter only with consent, privacy and maintenance plan

## Open Decisions

The following remain intentionally unresolved:

- final ancient-tree identity and lore
- release order of Little Explorer and Petal Nook
- final world-specific key art
- final logo animation
- whether the website will support additional languages at launch
- final support and press email structure

Do not silently resolve these in code.

## Release Checklist

Before any production deployment:

- [ ] no broken links
- [ ] no false store buttons or release claims
- [ ] correct domain and canonical metadata
- [ ] privacy page available
- [ ] email address tested
- [ ] images optimised
- [ ] accessibility review complete
- [ ] reduced motion supported
- [ ] no secrets in source
- [ ] documentation reflects the deployed direction
