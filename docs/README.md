# Orlumi Documentation

This folder is the maintained source of truth for the Orlumi brand website and its connected worlds.

## Read Order

1. [`ORLUMI_BIBLE.md`](./ORLUMI_BIBLE.md) — highest-level brand truth
2. [`WEBSITE_GUIDE.md`](./WEBSITE_GUIDE.md) — website purpose, structure and expansion rules
3. [`DESIGN_SYSTEM.md`](./DESIGN_SYSTEM.md) — visual tokens, layout, motion and accessibility
4. [`ART_DIRECTION.md`](./ART_DIRECTION.md) — illustration and environmental art direction
5. [`UI_UX_GUIDE.md`](./UI_UX_GUIDE.md) — interaction and responsive behaviour
6. [`COPYWRITING.md`](./COPYWRITING.md) — public-facing voice and wording
7. [`LORE.md`](./LORE.md) — approved world-building boundaries
8. [`NAMING_GUIDE.md`](./NAMING_GUIDE.md) — title, feature and lore naming rules
9. [`AI_RULES.md`](./AI_RULES.md) — mandatory instructions for AI-assisted changes
10. [`ROADMAP.md`](./ROADMAP.md) — implementation phases and content dependencies

## Authority

When documents conflict, follow this order:

1. Owner’s latest explicit decision
2. `ORLUMI_BIBLE.md`
3. Relevant specialist guide
4. Current code

Current code is an implementation, not the final authority.

## Maintenance Rule

Any major change to brand positioning, lore, naming, visual identity or website structure must update the relevant documentation in the same change.
